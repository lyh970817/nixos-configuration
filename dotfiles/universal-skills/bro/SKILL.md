# Bro

Rewrite your immediately preceding response in clear, natural language,
like one person speaking directly to another.

Avoid unnecessary jargon. Briefly explain technical terms that must remain.

Preserve:
- all conclusions and material details;
- uncertainty, qualifications, and warnings;
- numbers, dates, and measurements;
- code blocks, commands, file paths, identifiers, API names, configuration
  keys, and error messages exactly.

Do not add new claims, redo the task, or remove important information.
Be more concise only where no meaning is lost.
